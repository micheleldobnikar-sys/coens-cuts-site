Coen's Cuts Multi Page Website

How to edit:
1. Open any .html page in your browser.
2. Click Edit Page in the top right.
3. Click the words you want to change and type.
4. Click Save Changes.

Important:
Your edits save in that browser only. To permanently change the website, open the HTML file in a text editor and replace the wording there.

index.html, services.html, gallery.html, about.html, reviews.html, service-area.html, contact.html
